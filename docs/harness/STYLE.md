# STYLE — 룰·정본 문서 작성 규범

CLAUDE.md·rules·harness 문서 전체에 적용되는 작성 규범.
목적 하나: **문서가 조용히 썩는 것을 구조적으로 막는다.**

## 1. 단일 소유 (한 사실 = 정본 1곳)

- 한 사실의 본문은 정본 파일 1곳만 소유한다. 다른 문서는 `정본 = 링크` 1행만 —
  **요약 재서술도 금지** (요약은 낡아도 아무도 모른다).
- CLAUDE.md 의 룰 = 트리거 + 결론 1~2줄 + 포인터. 절차·포맷·예시는 rules 파일만.
- 안전-critical 이라 의도적으로 복제할 땐 `mirror-of: {정본}` frontmatter 필수.

## 2. 금지·단언·폐기의 형식

- **금지는 ⛔ 접두** — grep 한 번으로 전수 수집 가능하게. 금지엔 반드시 대안을 짝지운다.
- **상태 단언에는 재검증 명령 동봉** — "현재 위반 0건" 옆에 grep 원라이너.
- **폐기 3요소 고정**: `⛔폐기(YYYY-MM-DD → 대체: {경로})`. 인라인 괄호 주석 금지.
- **룰 변경 스탬프**: `(YYYY-MM-DD 확정 — 근거: {follow-up 문서/커밋})` 짝지음.

## 3. 예외는 콜아웃 누적이 아니라 본문 재스코프로

아키텍처 분기(새 런타임·새 경로)가 생겼을 때 기존 절대문에 blockquote 예외를
덧붙이는 것은 **임시 1회만** 허용한다. 다음 편집에서 절대문 자체에 스코프를
한정하거나(`(src/app 한정)`) 경로별 섹션으로 재구조화한다 — 콜아웃이 쌓이면
본문 절대문이 절반의 코드베이스에서 거짓이 된다 (원본 프로젝트 실측).
런타임/스택이 2개 이상인 패키지는 횡단 룰 × 소스트리 커버리지 표를 두어
공백 셀(사각)을 구조적으로 노출한다.

## 4. 언어 정책

- 문서 언어: **한국어**. 신규 문서부터 적용
  (기존 문서 일괄 번역은 요구하지 않음).
- 코드 주석 / UI 문자열 언어는 각 패키지 CLAUDE.md 가 정한다.

## 5. 템플릿 슬롯 표기 규약

- **채울 슬롯 = `<...한글...>`** (또는 `<dev|main>`). 설치·설정 시 반드시 실제 값으로
  치환된다. 린트 ①이 잔존을 전수 검출한다.
- **영구 관례 표기 = `{...}`** (예: `docs/harness/{트랙}.md`). **이 파일 안에서는**
  채우지 않으며 린트가 무시한다. 복사해 쓰는 템플릿(예: rules frontmatter)의 `{...}` 는
  복사본에서 실제 값으로 치환한다.
- 새 템플릿·문서를 쓸 때 이 규약을 지켜야 린트가 유효하다.

## 6. 기계 검증

- 반복 실수를 막는 룰은 가능하면 grep/스크립트로 환원한다.
- 하네스 린트 `scripts/harness-check.sh` 가 잡는 것: 미치환 슬롯 · 죽은 참조 ·
  고아 rules · 트랙 인덱스 불일치 · gitignore 함정 · 스크립트 CRLF/실행권한.
  handoff 전에 한 번 돌리는 것을 권장.
- 동반갱신 계약은 [`sync-contracts.md`](sync-contracts.md) 레지스트리에만 등록.
