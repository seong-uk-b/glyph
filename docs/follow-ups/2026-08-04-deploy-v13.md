# v1.3 배포 및 배포 경로 정리

**상태**: in-progress (웹 배포·경로 정리 완료 / 실기기 재설치만 남음)

## 문제 (해결됨)

배포를 시도하다 **배포 경로가 두 개로 갈라져 있는 것**을 발견했다 (2026-08-04):

1. **실제 경로** = `.github/workflows/deploy.yml` — `main` push 시 Actions 가 빌드해
   Pages 아티팩트로 배포 (`gh api .../pages` 의 `build_type: workflow`)
2. **죽은 경로** = `npm run deploy` (gh-pages 패키지) — gh-pages 브랜치에 push 하지만
   Pages 가 그 브랜치를 읽지 않으므로 **아무 효과 없음**

게다가 1번이 `npm ci` 락파일 검증 실패로 깨져 있어서, push 해도 사이트는 v1.0 을
계속 서빙하고 있었다. 사이트가 200 을 반환하므로 겉으로는 정상으로 보였고,
**라이브 번들 해시를 로컬 빌드와 대조해서야** 발견했다.
