# v1.3 웹 배포 및 실기기 재설치

**상태**: open
**우선순위**: P2 (보통)
**예상 공수**: ~15분
**의존성**: 없음 (N2/N1 확장 후로 미뤄 v1.4와 묶어도 됨)

## 문제

v1.1~v1.3 변경(발음 mp3 4,698+1,060개, TOPIK 확장, 복습/듣기 모드, JLPT 재배정)이
로컬 커밋에만 있고 아직 배포되지 않았다:
- 웹(GitHub Pages): 마지막 배포가 v1.0 시점
- 아이폰 실기기: 세이프에어리어 수정 시점 빌드 (mp3·신규 기능 미포함)

## 제안 (스텝별)

1. `npm run deploy` — 웹 배포 (mp3 ~75MB 포함되므로 첫 배포가 다소 걸림)
2. 아이폰 USB 연결 → `npx cap open ios` → ▶ 실행 (재서명 겸함)
3. 검증: 배포 URL 접속 → 단어 퀴즈 발음이 Neural 음성인지 확인

## 리스크 / 트레이드오프

- gh-pages 브랜치 용량 증가 (저장소 1GB 한도 대비 ~80MB 수준이라 여유 있음)
