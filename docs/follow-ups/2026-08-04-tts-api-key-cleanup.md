# 노출된 Google TTS API 키 삭제

**상태**: open
**우선순위**: P0 (긴급)
**예상 공수**: ~5분
**의존성**: 없음 (단, N2/N1 mp3 생성 전에 삭제하면 새 키 발급 필요)

## 문제

발음 mp3 생성에 쓴 Google Cloud TTS API 키가 에이전트 대화 로그에 평문으로
노출되었다. TTS 전용으로 API 제한이 걸려 있어 피해 범위는 작지만, 노출된 키는
삭제하는 것이 원칙이다.

## 제안 (스텝별)

1. console.cloud.google.com → API 및 서비스 → 사용자 인증 정보 → 해당 키 삭제
2. JLPT N2/N1 확장(트랙 `jlpt-expansion`)의 mp3 생성이 남아 있으므로,
   그 작업 직전에 새 키를 발급(애플리케이션 제한 "없음", API 제한 "TTS만")해서 쓰고
   끝나면 다시 삭제하는 사이클을 권장.

## 리스크 / 트레이드오프

- 방치 시: 무료 한도(월 100만 자) 소진 가능성 (결제 예산 알림 $1 설정돼 있으면 통보됨)
